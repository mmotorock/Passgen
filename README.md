# Passgen - A Rust-Based Password Generator

Passgen is a versatile, secure password and passphrase generator built with Rust and the `egui` library. It provides both a user-friendly graphical interface (GUI) and a scriptable command-line interface (CLI) for all your password needs.



## Features

-   **Dual Mode:** Operates as a full GUI application or as a command-line tool.
-   **Six Password Styles**, each with its own options:

    | Style | Example | Size |
    |---|---|---|
    | **Random** | `q7@Mdf#2kTae!9xH` | 12–256 characters |
    | **Segmented** | `asd2qwe+YUI6xcv4` | 12–256 characters |
    | **Grouped** | `hupvew-7hiTwa-qasnob` | 2–5 blocks of 6 |
    | **Pronounceable** | `Kavo-temi48-Rupa-zeku` | 3–8 made-up words |
    | **PIN** | `583061` | 4–12 digits |
    | **Words** | `Mango-Otter-Kettle-Robin` | 3–8 words |

    -   **Random:** every character picked at random from the selected sets. No character appears twice in a row, and each appears at most 3 times (raised automatically only for very long passwords).
    -   **Segmented** (the default): letters in groups of 3 of the same case, each followed by a number or a symbol, about three numbers for every symbol, always including every selected set. Reading it out only needs "capitals" or "lowercase" once per group. If only letters, or no letters, are selected, it falls back to Random.
    -   **Grouped:** like the passwords Apple suggests: blocks of 6 lowercase letters joined by dashes, with exactly one capital and one digit. Easy to type on a phone.
    -   **Pronounceable:** made-up words of easy consonant–vowel syllables, some capitalised, optionally with a two-digit number.
    -   **PIN:** digits 0–9, avoiding obvious patterns such as `111111` or `123456`.
    -   **Words:** a passphrase from a built-in list of about 900 common words (fruit, animals, food, everyday objects, nature...), optionally with a two-digit number, with your choice of capitalisation and separator. The list is generated by `tools/build_wordlist.py`; edit the categories there and run `python3 tools/build_wordlist.py words.txt` to change it, or choose your own wordlist (one word per line) in the settings.
-   **Readable by Default:** the default character sets (used by Random, Segmented and Grouped) are chosen to be easy to read out, e.g. over the phone: they leave out look-alikes (`0 O o 1 l I B`), uppercase letters that look like their lowercase (`C K P S U V W X Z`), and symbols that are tiny or hard to name (quotes, brackets, `| ; : , . _ ^`). Edit the sets to change this.
-   **Password History:**
    -   The last 10 generated passwords (GUI and CLI) are listed under the generated password (about 5 at a time; the rest scroll), hidden until you tick "Show", each with a Copy button.
    -   Every password you get to see is recorded: the one generated (and copied) when the app starts or when you switch style, every one from ↻ or `Space`, and the one shown after you change an option once it has stayed on screen for a second (so dragging a slider doesn't fill the history with every step).
    -   The history is stored encrypted (ChaCha20-Poly1305) in `history.dat`. The key is kept in the operating system's keyring (Windows Credential Manager, GNOME Keyring/KWallet on Linux, Keychain on macOS), so the file alone is useless to anyone who copies it.
    -   If no keyring is available, the history is kept for the current session only.
-   **Quick to Use:**
    -   A password is generated and copied as soon as the app opens and whenever you switch style. Changing an option shows a new one straight away (without copying it).
    -   Next to the password: **↻** generates a new one and copies it, **copy** copies the current one, and **🔊** spells it out. When something is copied, the button shows a check mark and the copied text flashes as if selected.
    -   The clipboard is cleared after 2 minutes (only if it still holds that password).
    -   Keyboard shortcuts for everything you do often, including switching styles (see [Keyboard Shortcuts](#keyboard-shortcuts)).
    -   Settings that can't produce a password (e.g. no character set selected) are explained right under the password.
-   **Easy to Read Out:**
    -   Digits and symbols are shown in their own colours, so "capital, digit, symbol" is visible at a glance.
    -   **🔊 Spell it out** shows the password in the NATO phonetic alphabet, grouped the way you'd read it: `asd2qwe+YUI6` becomes *alfa sierra delta · two · quebec whiskey echo · plus · capitals YANKEE UNIFORM INDIA · six*. It stays on until you turn it off (not shown for the Words style).
    -   The character sets themselves are hidden behind **Edit characters…**, so the window stays compact; the four checkboxes are always visible.
-   **Full Configuration:**
    -   All settings are saved automatically to a `config.toml` file as you change them.
    -   Choose which style the app opens on.
    -   Custom wordlists can be used by changing the path in the settings.
    -   Colour themes: Light and Dark, plus Gruvbox Dark/Light, Solarized Dark/Light and Nord out of the box. Add your own by dropping a `.toml` file in the themes folder.
-   **Cross-Platform:** Built with Rust, it compiles to a single, native executable.
-   **Secure:** Uses the `rand` crate for cryptographically secure random number generation.

## Prerequisites

To build this project from the source, you will need:

1.  **The Rust Toolchain:** Install Rust from [rustup.rs](https://rustup.rs/).
2.  **Windows Build Tools (for Windows users):**
    -   You must use the **MSVC toolchain**. You can install it by running `rustup toolchain install stable-msvc`.
    -   You also need the **Visual Studio Build Tools** with the "Desktop development with C++" workload and the latest **Windows SDK** component installed. This is required to compile resources and embed the application icon.

## Installation & Running

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/mmotorock/Passgen.git
    ```
   
2.  **Navigate to the project directory:**
    ```bash
    cd Passgen
    ```

3.  **Build the project in release mode:**
    This command will compile the application with full optimizations and create a standalone executable.
    ```bash
    cargo build --release
    ```

4.  **Run the application:**
    -   The final executable will be located in the `target/release/` directory.
    -   On Windows, this will be `Passgen.exe`.

### Installing on Linux

To install Passgen for your user, with a launcher in the app menu and its icon in the dock, run:

```bash
packaging/linux/install.sh
```

This builds a release version and installs:

| File | Purpose |
|---|---|
| `~/.local/bin/passgen` | The program (add `~/.local/bin` to your `PATH` to run `passgen` in a terminal) |
| `~/.local/share/applications/passgen.desktop` | App menu launcher |
| `~/.local/share/icons/hicolor/128x128/apps/passgen.png` | Icon |

Run it again after pulling changes to update. To uninstall, run `packaging/linux/install.sh --remove` (your settings and history are kept).

On Wayland desktops such as GNOME, an app can't set its own window icon: the dock finds the icon through the installed `passgen.desktop` file, which matches the app's ID (`passgen`). Without installing it, Passgen shows a generic icon.

## Usage

### GUI Mode

Simply double-click the executable to launch the graphical user interface. The application creates a default `config.toml` on first launch.

All settings and the history live in the config folder:

| Platform | Config folder |
|---|---|
| Windows | `config\` next to `Passgen.exe` |
| Linux / macOS | `~/.config/passgen/` (or `$XDG_CONFIG_HOME/passgen/`) |

The word generator uses its built-in list unless you choose a custom wordlist in the settings.

`config.toml` is a standard TOML file, so it can be edited by hand while the app is closed:

```toml
theme = "nord"                # "light", "dark" or a file name from the themes folder
default_style = "Segmented"   # Random, Segmented, Grouped, Pronounceable, Pin or Words
words_file_path = ""          # empty = built-in wordlist

[characters]                  # sets used by Random, Segmented and Grouped; length for Random
length = 16                   # 12 to 256
use_special = true
special = "!@#$%&*+=?-"
# ...

[segmented]
length = 16                   # 12 to 256

[grouped]
groups = 3                    # 2 to 5

[pronounceable]
groups = 4                    # 3 to 8
include_number = true

[pin]
length = 6                    # 4 to 12

[words]
count = 4                     # 3 to 8
separator = "-"
capitalize = true
include_number = false
```

Missing or invalid entries fall back to their defaults (and are reported in the status bar). Config files from earlier versions are converted automatically, keeping the original as `config.toml.bak`.

### Keyboard Shortcuts

| Key | Action |
|---|---|
| `Space` | Generate a new password and copy it |
| `Ctrl+C` | Copy the password on screen (or the text you've selected) |
| `Tab` / `Shift+Tab` | Next / previous style |
| `→` / `←`, or `l` / `h` (as in Vim) | Next / previous style |
| `1` – `6` | Jump to a style |

The style numbers follow the order of the buttons:

| Key | Style |
|---|---|
| `1` | Random |
| `2` | Segmented |
| `3` | Grouped |
| `4` | Pronounceable |
| `5` | PIN |
| `6` | Words |

Switching style generates a new password in that style and copies it, just like clicking its button. Style switching wraps around: `→` on Words goes to Random.

The shortcuts are off while you're typing in a text field (such as the character sets or the length box), so letters and numbers go into the field as usual; click outside it or press `Esc` to use them again. They're also off while a dropdown in the settings is open.

### Themes

Pick a colour scheme in **Settings (⚙, top right) → Color scheme**. Besides egui's built-in **Light** and **Dark**, Passgen reads every `.toml` file in the `themes` folder inside the config folder (`~/.config/passgen/themes/` on Linux, `config\themes\` next to `Passgen.exe` on Windows). The first time it runs, it puts these there:

| Theme | File |
|---|---|
| Gruvbox Dark | `gruvbox-dark.toml` |
| Gruvbox Light | `gruvbox-light.toml` |
| Nord | `nord.toml` |
| Solarized Dark | `solarized-dark.toml` |
| Solarized Light | `solarized-light.toml` |

They are only created when the folder doesn't exist yet, so you can edit or delete them freely. The originals are in the [`themes/`](themes/) folder of this repository.

To make your own theme, copy one of the files under a new name and change the colours. **Settings → Open Themes Folder** opens the folder, and **Reload Themes** picks up your changes without restarting. The file name (without `.toml`) is the theme's ID; a file named `light.toml` or `dark.toml` replaces that built-in theme.

```toml
name = "My Theme"      # shown in the settings (defaults to the file name)
dark = true            # start from egui's dark (true) or light (false) theme

[colors]               # all optional, as "#rrggbb" or "#rrggbbaa"
background    = "#2e3440"   # window and panel background
surface       = "#272c36"   # text fields and other recessed areas
text          = "#d8dee9"   # normal text and icons
weak_text     = "#8a93a5"   # descriptions, timestamps and hints
strong_text   = "#eceff4"   # text on buttons while pressed, headings
widget        = "#3b4252"   # buttons, checkboxes, sliders
widget_hover  = "#434c5e"   # the same, under the mouse
widget_active = "#4c566a"   # the same, while pressed
border        = "#3b4252"   # separators and outlines
accent        = "#88c0d0"   # the selected style button, selected text
accent_text   = "#2e3440"   # text drawn on the accent colour
error         = "#bf616a"   # warnings under the password
success       = "#a3be8c"   # the check mark after copying
digit         = "#81a1c1"   # digits in passwords
symbol        = "#d08770"   # symbols in passwords
```

A theme file with a mistake (such as a misspelt colour name or a colour that isn't `#rrggbb`) is skipped, and the status bar says why. If the selected theme's file is removed, Passgen falls back to Dark.

### Command-Line Mode (CLI)

Give Passgen a style or a size to use it from a terminal or a script. The result is printed, copied to the clipboard and added to the history, just like in the GUI.

The CLI uses the **settings saved by the GUI**. The options below override them for a single run; nothing is saved.

```text
passgen [-s STYLE] -n LENGTH [OPTIONS]    random, segmented or pin
passgen [-s STYLE] -g GROUPS [OPTIONS]    grouped or pronounceable
passgen -w WORDS [OPTIONS]                words
passgen -s STYLE [OPTIONS]                any style, with its saved size
```

Without `-s`, Passgen uses your default style if it fits the size option, and otherwise Segmented for `-n`, Grouped for `-g` and Words for `-w`.

(When running from the build folder instead of an installed copy, use `./target/release/Passgen`, or `Passgen.exe` on Windows.)

#### General options

| Option | Description |
|---|---|
| `-s`, `--style <STYLE>` | `random`, `segmented`, `grouped`, `pronounceable`, `pin` or `words`, or the style's number `1`–`6` (the same numbers as the [GUI shortcuts](#keyboard-shortcuts)) |
| `-n`, `--length <LENGTH>` | Length: 12 to 256 for random and segmented, 4 to 12 for pin |
| `-g`, `--groups <COUNT>` | Number of groups: 2 to 5 for grouped, 3 to 8 for pronounceable |
| `-w`, `--words <COUNT>` | Number of words (3 to 8); on its own it also selects the words style |
| `-c`, `--count <N>` | Generate N results (1 to 100), one per line. All of them are copied and added to the history. |
| `--no-copy` | Don't copy the result to the clipboard |
| `--no-history` | Don't add the result to the history |
| `-h`, `--help` | Show all options |
| `-V`, `--version` | Show the version |

#### Style options

| Option | Styles | Description |
|---|---|---|
| `--no-lowercase`, `--no-uppercase`, `--no-numbers`, `--no-special` | random, segmented | Leave out a character set. These only turn sets off; a set turned off in the settings stays off. |
| `--number` / `--no-number` | pronounceable, words | Include, or don't include, a two-digit number |
| `--separator <CHAR>` / `--no-separator` | words | Put this character between words, or none |
| `--capitalize` / `--no-capitalize` | words | Start every word with an uppercase letter, or keep them lowercase |
| `--wordlist <FILE>` | words | Use this wordlist (one word per line) instead of the saved one |

Using an option with a style it doesn't apply to is an error, e.g. `passgen -s pin --no-special`.

#### Examples

```bash
passgen -n 16                          # 16 characters in your default style (Segmented unless changed)
passgen -s random -n 20 --no-special   # letters and numbers only
passgen -s segmented -n 20             # e.g. qwe7ADF4zxv2HJL&mnb9
passgen -s grouped                     # e.g. hupvew-7hiTwa-qasnob
passgen -s pronounceable -g 5          # e.g. Kavo-temi-Rupa48-zeku-Bafi
passgen -s pin -n 6                    # e.g. 583061
passgen -s 5 -n 6                      # the same, with the style's number
passgen -w 4 --number                  # e.g. Mango-42-Otter-Kettle-Robin
passgen -w 4 --no-separator --no-capitalize   # e.g. mangootterkettlerobin
passgen -n 16 -c 10 --no-copy          # print ten passwords, don't touch the clipboard
passgen -n 16 --no-copy --no-history   # for scripts: just print it
```

The password is written to standard output and messages (such as "Copied to clipboard.") to standard error, so `PASSWORD=$(passgen -n 16 --no-copy)` captures only the password. Passgen exits with status 0 on success, 1 if no password could be generated (for example, a size out of range, all character sets turned off, or the wordlist can't be read) and 2 for invalid options.
